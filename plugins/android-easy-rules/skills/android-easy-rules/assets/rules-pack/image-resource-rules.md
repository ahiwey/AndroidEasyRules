# Android Image / Icon Resource Rules

## 资源放置

- 新增图片前先查同类资源所在目录。
- bitmap 资源使用小写下划线命名，并带业务前缀，例如 `ic_meeting_*`、`home_*`、`sleep_*`。
- 不要使用临时名、中文名、空格或设计稿原始文件名。
- 不要把无关品牌素材、截图原图、设计稿、临时素材放进 `res`。

## PNG / WebP / XML Drawable 选择

- 复杂位图、渐变、照片类素材使用 PNG/WebP。
- 简单圆角、边框、selector、纯色背景优先 XML drawable。
- 不要为了“现代化”强行把所有图标改成 vector。
- 不要把已有项目风格完全打散。

## 使用规则

- 保持图标宽高比和透明边距。
- XML 中通过明确宽高、`scaleType`、约束和内外边距控制显示。
- 不要用拉伸填满导致变形。
- 新增可点击图片按钮时，补充可访问性描述或明确其文本语义。
- 纯装饰图不要加入误导性文案。

## 多主题与设计稿资源复用

- 项目存在用户可见的主题页入口时，按支持多主题处理。文字颜色、背景色和相关 style 原则上复用项目已有的主题资源或语义色，不新增资源或硬编码；黑色、白色尤其要先查现有定义。确认项目没有合适资源时，先询问用户新增方式、命名和各主题取值，再实施。
- 多主题项目中的黑白单色图标必须设置主题感知的 `imageTint`，复用项目已有的 tint/`ColorStateList` 或对应主题色；XML、View 和 Compose 使用项目当前技术栈的等价 tint 写法。多彩图标不得机械套 tint。
- UI 图或效果图中出现但用户未提供的图标，先按图标语义、相似页面和资源命名搜索项目已有的 `drawable`、`mipmap`、`assets` 及图标组件。确认项目没有合适资源时，询问用户图标文件或来源位置；未经确认不得自行生成、绘制或用近似图标替代。

## 切图应用与公共资源替换

- 先从同职责页面、组件和资源映射判断复用：按钮、日期/时间/分钟选择器、输入项、卡片、类型名称与图标。按“原样复用、调整公共样式、替换公共素材、局部新增”记录在已有短表，不另建清单。
- 新旧图实际查看后核对格式、像素与逻辑尺寸、源倍率、透明边距、自带背景及状态。沿用项目密度约定，未知倍率不能直接视为 xxhdpi；设计坐标比例不等于切图导出倍率。只导入实际用到的素材，保留来源和原文件。
- 用户已明确要求公共替换或确认的方案包含该范围时，沿用原资源类型和名称实施，无需重复确认。仅要求本页还原时检查引用影响，优先局部样式；只有确需扩大范围才确认增量。
- 替换前沿资源名核对定义、别名、selector、style 和实际调用，以及项目存在的密度、night、flavor/source set、主题/皮肤变体。防止更高优先级目录仍使用旧图；只追相关引用，不全仓展开。
- 同名替换按核实的源倍率处理，不把一张位图原样复制到各密度目录，不擅自删除旧变体。缺少对应素材的变体保留并报告边界，部分覆盖不能称为全局替换完成。
- 检查调用方 tint、alpha、padding、scaleType、固定尺寸、compound drawable 和最小触控区；切图自带背景时避免重复加底。保留 View 类型/id、回调和可访问性语义，避免破坏绑定或强制类型转换。
- 简单背景优先复用现有语义色、style 和 XML 形状，只调整已授权范围的颜色、圆角或透明度；不同业务语义不因颜色相近就强行共用。无合适实现才按项目规则最小新增。
- 设计图背景不透明度只作用于背景，不用整个 View 的 alpha 淡化文字/图标。检查颜色、drawable、View 和父容器的 alpha 是否叠乘；已知底色时用原始色与透明度，截图取样合成色不能直接当半透明层原色。

## 验证

- 现有图片内容替换优先检查格式、尺寸、透明边距、引用和实际截图；新增/重命名资源或引用时运行一次最小资源处理任务。
- 只有用户要求 APK、改动打包配置，或最小资源任务无法覆盖集成边界时才运行 app assemble。
- 真机/模拟器自动化验证先遵循截图专项规则的询问流程；同意后检查关键页面实际显示，跳过或未授权时不探测设备并标注运行态/视觉未验证。
- 公共替换核对实际生效的变体，本次已同意自动化验证后抽查目标页与一个其他使用页的布局、状态和触控；跳过或无法运行时标明视觉未验证。编译通过不证明图像匹配或公共覆盖完整。
- 大量新增/替换图片时，检查 APK 体积和重复资源。

## 素材应用证据

- 可见图标保留“设计位置 → 已查看的切图/共用类型映射 → 项目资源名 → XML/运行绑定位置”；只复制到 res 不等于应用完成。同时核对 tint、selector 与覆盖变体。
- 批量难辨资源按需使用可用 Lanhu Skill 的 image_review.ps1 生成编号/原文件映射和深浅底预览；透明边界、尺寸、像素取样仅是辅助，不自动裁边，不用合成取样色替代原始半透明色。
- 引用难核对时按需使用 resource_usage.py，只传相关文件与 res 根目录；跟进 alias/style/include/动态绑定。not_found_in_scope 不是全仓未使用的证明，不据此删除资源。
- 语义色复用前解析实际值、状态和主题；指标/强调色不能滥用到标题、说明、单位。既有名字匹配但色值不符时，按授权范围局部适配或更新共用资源，不因复用要求保留明显错误。
